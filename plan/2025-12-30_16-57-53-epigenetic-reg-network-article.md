# Plan: 四种灵长类表观遗传调控网络文章

🎯 任务概述
你要基于本项目的数据与平台，写一篇围绕“人类、黑猩猩、猕猴、狨猴的表观遗传调控网络”的文章。
目标是把“数据资源 + 网络构建方法 + 跨物种比较结果 + 关键案例 + 可复现材料”组织成一套读者能复用的叙事与产物。

📋 执行计划
1. **文章定位与核心问题（已明确）**：文章类型为**学术论文（article）**。确定目标读者（数据库/资源论文读者）与核心结论句，并将研究问题收敛到 2–3 个可被数据支撑的问题（例如“保守性 vs 物种特异性”“表观遗传标记对调控边的分层”）。交付：`docs/paper/manuscript.md` 初稿骨架。
2. **数据清单与数据字典**：梳理四物种数据覆盖（基因、lncRNA、调控边、BA、序列、ChIP-seq/DNase/RepeatMasker 等），形成“字段→来源→过滤规则→限制”的数据字典与一张覆盖总表。
3. **数据提取与版本化**：选定数据抽取路径（优先 API 导出，其次直连数据库），导出每个物种的边表/点表与跨物种同源映射表；记录导出参数、时间戳与 commit sha，保证结果可追溯。
4. **网络构建与质控**：定义网络对象（节点/边/方向/权重）、阈值策略（如 BA cutoff、最小证据数），并做最小 QC（重复边、缺失坐标、极端值、样本量差异）与敏感性分析（阈值变化对结论的影响）。
5. **跨物种对齐与保守性分层**：基于同源基因映射将网络对齐到共同参照（例如 ortholog group），构建“保守边/模块”的定义；产出保守性分布、核心模块与物种特异模块清单。
6. **表观遗传层叠加分析**：把 ChIP-seq/DNase 等表观遗传特征映射到网络边或节点附近区域（例如 gene/lncRNA 区域±flanking），计算 mark 富集、bivalent 域、细胞系差异（如数据允许）并与网络层指标关联。
7. **关键图表与可视化产物**：为每个核心问题设计 1–2 张“定稿级”图（总览+比较+案例），并固定出图脚本与参数；必要时用 Playwright 脚本对前端可视化页面生成一致风格截图（用于论文/文章插图）。
8. **写作与方法/结果组织**：按“背景→数据资源→方法→结果→讨论→限制→数据/代码可用性”结构撰写；所有关键数字/图都要能回链到导出文件或脚本产物。
9. **可复现打包与最终校对**：整理一键复现入口（notebook/脚本运行顺序、环境说明、产物目录结构），进行交叉核对（图表数值一致、跨物种映射无明显错误），并完成最终润色与发布。

⚠️ 风险与注意事项
- **跨物种同源映射偏差**：ortholog 映射质量会直接影响“保守性”结论，必须在结果里给出定义、过滤规则与敏感性分析。
- **物种/标记/细胞系覆盖不均**：ChIP-seq/DNase 覆盖与样本量差异可能导致比较不公平，需要在方法中明确“可比子集”与限制。
- **阈值敏感性与多重比较**：BA cutoff、max_qvalue、网络筛选规则会改变网络形态；统计检验需控制多重比较并避免过拟合式阈值选择。
