# 2025-12-05 更新日志

## Phase 2.1: RepeatMasker 扩展层实现

### 概述

完成 Phase 2 扩展层的第一个数据类型 **RepeatMasker** 的全栈实现，包括数据库扩展、后端 API、前端组件和数据导入。

### 数据导入

- **数据来源**: UCSC Genome Browser hg19 RepeatMasker (rmsk.txt)
- **下载地址**: https://hgdownload.gi.ucsc.edu/goldenPath/hg19/database/rmsk.txt.gz
- **总记录数**: 5,481,341 条
- **导入耗时**: 229.5 秒 (~4 分钟)
- **导入速度**: 23,881 条/秒

### 重复类型分布

| Repeat Class | 数量 | 占比 |
|-------------|------|------|
| SINE | 1,859,995 | 33.9% |
| LINE | 1,550,361 | 28.3% |
| LTR | 742,462 | 13.5% |
| DNA | 475,314 | 8.7% |
| Simple_repeat | 439,608 | 8.0% |
| Low_complexity | 374,918 | 6.8% |
| 其他 | 38,143 | 0.7% |

## 后端更改

### 数据库 Schema

**新增表**:
- `feature_tracks` - 轨道配置/注册表
- `genomic_features` - 通用基因组特征（按 species_id 分区）
  - `genomic_features_human` (partition)
  - `genomic_features_chimp` (partition)
  - `genomic_features_macaque` (partition)
  - `genomic_features_marmoset` (partition)

**Schema 文件**: `schema/v2.3/04_extension_phase2.sql`

**索引策略**:
```sql
-- 每个分区独立索引
CREATE INDEX idx_gf_human_track ON genomic_features_human(track_id);
CREATE INDEX idx_gf_human_location ON genomic_features_human(chromosome, feature_start, feature_end);
CREATE INDEX idx_gf_human_chr_track ON genomic_features_human(chromosome, track_id);
CREATE INDEX idx_gf_human_attrs ON genomic_features_human USING GIN (attributes);
```

### SQLAlchemy Models

**新增文件**: `app/models/models.py` (扩展)

```python
class FeatureTrack(Base):
    __tablename__ = 'feature_tracks'
    track_id = Column(Integer, primary_key=True)
    track_name = Column(String(100), unique=True)
    track_category = Column(String(50))  # 'repeat', 'epigenetic', 'conservation'
    display_name = Column(String(200))
    display_color = Column(String(20))
    ...

class GenomicFeature(Base):
    __tablename__ = 'genomic_features'
    feature_id = Column(BigInteger, primary_key=True)
    track_id = Column(Integer, ForeignKey('feature_tracks.track_id'))
    species_id = Column(Integer, primary_key=True)  # Partition key
    chromosome = Column(String(50))
    feature_start = Column(BigInteger)
    feature_end = Column(BigInteger)
    attributes = Column(JSONB)  # {'repeat_class': 'LINE', 'repeat_family': 'L1', 'divergence': 12.3}
    ...
```

### 数据导入脚本

**新增文件**: `etl/import_ucsc_rmsk.py`

支持 UCSC rmsk.txt 格式导入，特性：
- 批量插入（默认 50,000 条/批）
- 进度显示
- 批次追踪（import_batches 表）
- 错误回滚

**使用方法**:
```bash
python3 etl/import_ucsc_rmsk.py /path/to/rmsk.txt --batch-size 50000
```

## API 示例

### 查询基因区域重复序列

```bash
curl "http://localhost:8000/api/v1/features/genes/23853/repeats?page_size=5"
```

响应：
```json
{
  "total": 60,
  "items": [
    {
      "feature_id": 878696,
      "chromosome": "chr11",
      "start": 111461818,
      "end": 111461982,
      "repeat_name": "AluJr4",
      "repeat_class": "SINE",
      "repeat_family": "Alu",
      "divergence": 16.5,
      "strand": "-",
      "score": 1124.0
    }
  ],
  "page": 1,
  "page_size": 5
}
```

### 查询区域重复序列

```bash
curl "http://localhost:8000/api/v1/features/repeats/1?chromosome=chr1&start=0&end=1000000"
```

### 获取重复类型列表

```bash
curl "http://localhost:8000/api/v1/features/repeats/1/classes"
# ["DNA", "LINE", "LTR", "SINE", "Simple_repeat", ...]
```
