# Changelog - 2025-12-06

## Phase 2.4: IGV ChIP-seq Track Integration

### New Features

#### 1. IGV.js ChIP-seq Track Support
- Added ChIP-seq tracks to GenomeBrowser with dynamic loading
- Supports 6 histone modification marks from ENCODE K562 data:
  - H3K27me3 (Repressive) - 88,069 peaks
  - H3K4me1 (Enhancer) - 125,713 peaks
  - H3K4me3 (Active Promoter) - 52,422 peaks
  - H3K27ac (Active Enhancer) - 58,937 peaks
  - H3K36me3 (Transcription) - 54,277 peaks
  - H3K9me3 (Heterochromatin) - 43,231 peaks
- Total: **422,649 peaks** imported from ENCODE

#### 2. Backend API Endpoints
New endpoints in `frontend/backend/app/routers/igv.py`:

| Endpoint | Description |
|----------|-------------|
| `GET /api/v1/igv/chipseq/marks/{species_id}` | Get available ChIP-seq marks for species |
| `GET /api/v1/igv/tracks/chipseq/{species_id}.bed` | Stream ChIP-seq peaks as BED format |
| `GET /api/v1/igv/config/chipseq/{species_id}` | Get IGV config with ChIP-seq tracks |

#### 3. Frontend Components

### Performance Optimizations

#### Data Limiting for Large Datasets
- Added `limit` parameter to BED endpoint (default: 50,000 records unless `chromosome+start+end` bounded region query)
- Added `max_records` parameter to `generate_chipseq_bed_stream()` function
- Prevents loading all 420k peaks at once

#### Region Filtering
- Backend supports `chromosome`, `start`, `end` parameters for region queries
- Region query window is capped at **10Mb** (DoS hardening)
- Database index `idx_chipseq_peaks_location` ensures fast region lookups
- Query time: ~0.2s for 10Mb region vs ~23s for full dataset

### Bug Fixes

#### 1. Mark Selection Shows Only Available Marks
- Fixed: Frontend was showing all configured marks instead of only those with data
- Changed `mark_type` to `mark_name` in API response handling
- Updated `ChIPSeqMarkInfo` interface to match API response

#### 2. Dynamic Track Management
- Fixed: Selecting ChIP-seq marks caused entire IGV browser to reinitialize
- Removed `chipseqMarks` from useEffect dependencies
- Added separate useEffect for dynamic track add/remove using `browser.loadTrack()` and `browser.removeTrack()`

#### 3. Empty Mark Handling
- Fixed: Requesting non-existent mark type returned 404, breaking IGV.js
- Now returns 200 OK with empty BED file (header only)

### UI Usage

1. Open GenomeBrowser page
2. Expand "Track Controls" section
3. Expand "ChIP-seq Tracks" subsection
4. Toggle "Enable ChIP-seq Tracks" ON
5. Select one or more marks from dropdown
6. Tracks will dynamically appear in IGV browser
