新增3个覆盖索引，优化分页排序查询性能：

| 索引名 | 表 | 定义 | 大小 |
|--------|-----|------|------|
| `idx_reg_ba_id` | regulations | `(binding_affinity DESC, regulation_id)` | 24 MB |
| `idx_reg_species_ba_id` | regulations | `(species_id, binding_affinity DESC, regulation_id)` | 31 MB |
| `idx_tga_trait_assoc` | trait_gene_associations | `(trait_id, association_id)` | 1.5 MB |

```sql
EXPLAIN SELECT * FROM regulations ORDER BY binding_affinity DESC LIMIT 100;
→ Index Scan using idx_reg_ba_id on regulations  ✅
```

## 🚀 一键启动脚本

### 新增脚本

| 脚本 | 功能 |
|------|------|
| `scripts/start.sh` | 一键启动前后端服务 |
| `scripts/stop.sh` | 一键停止服务 |

### start.sh 功能

```bash
./scripts/start.sh              # 开发模式启动全部
./scripts/start.sh -m prod      # 生产模式
./scripts/start.sh -b           # 仅启动后端
./scripts/start.sh -f           # 仅启动前端
```

**特性**:
- 环境检查（Python、Node.js、数据库连接）
- 开发/生产模式切换
- 自动安装前端依赖
- 健康检查验证
- 彩色日志输出

### stop.sh 功能

```bash
./scripts/stop.sh               # 停止全部服务
./scripts/stop.sh -s            # 查看服务状态
./scripts/stop.sh -b            # 仅停止后端
```

**特性**:
- 多种进程检测方式（PID 文件、进程名、端口）
- 优雅停止 + 强制停止回退
- 服务状态显示
