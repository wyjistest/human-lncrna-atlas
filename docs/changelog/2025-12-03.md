## 修复问题

### IGV.js 加载失败
- **问题**: `igv.createBrowser is not a function`
- **原因**: IGV.js ESM 导出需要访问 `.default` 属性
- **修复**: `module.default || module` 兼容两种导出模式

### FANTOM CAT 轨道不显示
- **问题 1**: 相对路径 `/genomes/` 请求到前端 5175 而非后端 8000
- **修复**: 前端组件自动转换为绝对 URL
- **问题 2**: 大文件默认限制可视窗口
- **修复**: 设置 `visibilityWindow: -1`

### API 数据提取错误
- **问题**: 前端期望 `IGVConfig`，实际收到 `{success, data: IGVConfig}`
- **修复**: `return res.data.data` 提取内层数据

## 性能优化：BED to bigBed 转换

### 概述

将 FANTOM CAT Transcripts 从 BED 格式转换为 bigBed 索引格式，大幅提升加载性能。

### 文件对比

| 格式 | 文件 | 大小 | 加载方式 |
|------|------|------|---------|
| BED | `fantom_cat_transcripts.bed` | 30 MB | 全量加载 |
| bigBed | `fantom_cat_transcripts.bb` | 7.2 MB | 按需加载 (byte-range) |

**压缩率**: 76%

### 技术实现

- 使用 UCSC `bedToBigBed` 工具 (v2.7)
- R-tree 索引支持随机访问
- 8 级预计算缩放

### 性能提升

| 指标 | BED | bigBed | 提升 |
|------|-----|--------|------|
| 首次加载 | 全量 30MB | ~100KB/区域 | **~300x** |
| 导航延迟 | 客户端过滤 | 索引查询 | **即时** |
| 浏览器内存 | ~100MB | ~10MB | **-90%** |

## 新功能：BED12 外显子/内含子结构

### 概述

将 FANTOM CAT Transcripts 从 BED6 升级为 BED12 格式，支持显示外显子/内含子结构。

### BED12 格式

```
chrom  chromStart  chromEnd  name  score  strand  thickStart  thickEnd  itemRgb  blockCount  blockSizes  blockStarts
```

### 数据转换

- 脚本: `scripts/gtf_to_bed12.py`
- 输入: `FANTOM_CAT.lv3_robust.gtf` (531MB)
- 输出: `fantom_cat_transcripts_bed12.bb` (18MB bigBed)

### 统计信息

| 指标 | 数值 |
|------|------|
| 总转录本 | 473,134 |
| 多外显子 (>1) | 418,306 (88.4%) |
| 单外显子 | 54,828 (11.6%) |
| 最多外显子 | 363 个 |

### 可视化效果

```
RefSeq 风格显示：
━━━━━━━╸━━━━━━━━━╺━━━━━━━━━━╸━━━━━
exon1    intron    exon2   intron   exon3
```

### Name 字段简化

- **旧格式**: `gene_id|transcript_id` (如 `CATG00000000011.1|ENCT00000005542.1`)
- **新格式**: `gene_id` (如 `CATG00000000011.1`)

## 技术评估：UCSC Genome Browser 集成可行性

### 评估结论

| 方案 | 推荐度 | 说明 |
|------|--------|------|
| **保持 IGV.js + bigBed 优化** | ⭐⭐⭐⭐⭐ | 当前最佳方案 |
| 添加 UCSC 链接按钮 | ⭐⭐⭐⭐ | 可选，用于深度分析 |
| UCSC Track Hub | ⭐⭐⭐ | 需公网服务器 |
| iframe 嵌入 | ⭐⭐ | 跨域问题多 |

### 推荐策略

1. **保持 IGV.js** 作为主视图（快速预览）
2. **可选** 添加 "Open in UCSC" 按钮（深度分析）
3. **bigBed 格式** 已解决主要性能问题
