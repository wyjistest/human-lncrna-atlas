# Current Roadmap Pointer

本页是“当前路线图”的稳定入口，避免开发者每次都去猜最新的日期文件名。

## 当前路线图

- 当前 1–2 周路线图：`docs/ROADMAP_2026-02-03.md`

## 使用约定

- 日期化 `docs/ROADMAP_YYYY-MM-DD.md` 文件继续保留为历史快照
- `docs/README.md`、`docs/CURRENT_STATUS.md` 等开发入口只应链接到本页
- 当出现新的路线图快照时，只更新本页指向，不在多个入口文件里重复硬编码日期文件名
