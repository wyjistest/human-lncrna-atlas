## 1) 本周（1 周）优先级：CI 连续性与维护性

### 1.1 GitHub Actions 可用性（P0）
- 明确 CI 无法启动的根因（账单/额度/组织策略），给出可选止损方案：
  - 修复 GitHub Billing / spending limit（推荐，最小变更）。
  - 迁移到 self-hosted runner（适合长期/高频 CI）。
  - 若仓库可公开：切换为 public repo 以使用免费额度（需评估数据/隐私）。
- 当前策略：`main` 分支 `push` 自动触发 `Tests`，`Security Audit` 在依赖清单变化时自动触发；同时保留 `workflow_dispatch` 作为随时可复现入口。本周验收以本地 `./scripts/run-tests.sh ci` 全绿 + self-hosted Actions 全绿为准。
- 验收标准（可选，待恢复额度后）：main 分支 push 能稳定触发 `Tests` 与 `Security Audit`，且非“Not started due to billing”。

### 1.2 前端去 deprecated（P1）
- 扫描并持续清理 AntD v6 deprecations（以构建/控制台 warning 为准），避免未来升级集中爆雷。
- 验收标准：`npm run build` 无与 AntD props 相关的 TS/console warning（可接受第三方库 warning）。

## 2) 下周（2 周）方向：回归锚点扩展 + 性能可解释

### 2.1 回归锚点（P1）
