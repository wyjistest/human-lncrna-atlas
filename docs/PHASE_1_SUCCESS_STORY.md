## 📈 数据洞察（chr1 染色体）

### 惊人发现

从 chr1 的 219,213 个重叠中，我们发现：

1. **lncRNA 调控的广泛性**
   - 1,706 个不同的 lncRNA 参与调控
   - 每个 lncRNA 平均影响 128 个重叠位点

2. **靶基因的集中性**
   - 仅 519 个靶基因
   - 每个靶基因平均被 422 个重叠位点调控
   - **提示**：某些关键基因受到多重表观遗传调控

3. **表观遗传标记的多样性**
   - 7 种 marks 都有重叠
   - H3K36me3（激活标记）数量最多
   - 平均 Peak 强度 17.1（中等强度）

4. **细胞特异性**
   - 4 个细胞系都有数据
   - 不同细胞系显示不同的调控模式

### 科研价值示例

**案例 1: RP11-243A14.1 调控 KIF21B**
```json
{
  "lncrna_name": "RP11-243A14.1",
  "target_gene_name": "KIF21B",
  "mark_type": "H3K36me3",
  "overlap_length": 1140,
  "binding_affinity": 495.01
}
```

**生物学意义**:
- lncRNA RP11-243A14.1 在其结合位点处富集 H3K36me3（激活标记）
- 重叠长度 1,140 bp，强相互作用
- 高结合亲和力（495.01），稳定结合
- **推断**：该 lncRNA 可能通过招募组蛋白修饰酶激活靶基因 KIF21B

## 🛠️ 技术创新亮点

### 1. 基因组区间重叠算法

**SQL 实现**（高效）:
```sql
-- 区间重叠条件（PostgreSQL 优化）
r.best_peak_start < p.peak_end
AND r.best_peak_end > p.peak_start

-- 重叠区间计算
GREATEST(r.best_peak_start, p.peak_start) AS overlap_start
LEAST(r.best_peak_end, p.peak_end) AS overlap_end
LEAST(r.best_peak_end, p.peak_end) - GREATEST(r.best_peak_start, p.peak_start) AS overlap_length
```

**性能**:
- SQL 执行时间：2.9 ms ✅
- 使用空间索引：idx_regulations_igv
- 支持染色体分区查询

### 2. 灵活的筛选系统

**12 个筛选维度**:
```typescript
{
  lncrna_gene_id,      // 特定 lncRNA
  target_gene_id,      // 特定靶基因
  mark_type,           // 组蛋白修饰（多选）
  cell_type,           // 细胞系（多选）
  chromosome,          // 染色体
  min_overlap_length,  // 最小重叠长度
  min_binding_affinity,// 最小 BA
  min_peak_strength,   // 最小 Peak 强度
  max_qvalue,          // 最大 Q-value
  page,                // 分页
  page_size,           // 每页大小
  sort_by              // 排序字段
}
```

**用户体验**:
- 支持任意组合筛选
- 实时响应（前端缓存 30 分钟）
- 智能默认值
