# Docs TODO Cleanup 2 Design

## 背景与目标

部分历史计划文档仍保留大量未勾选清单与 Mock 安装步骤，容易被误解为“当前待办”。本次目标是在不删除历史内容的前提下，显式标注这些清单为历史记录，并指向已完成的真实实现或最新状态文档，降低误用风险。

## 方案对比

**方案 A（最小干预）**：在相关章节顶部增加“历史说明”，保持原清单与示例不变，仅改变语义。  
**优点**：改动最少、可追溯；**缺点**：未勾选清单仍可能被误读。

**方案 B（语义重写）**：将未勾选清单改为“历史记录”，把 `[ ]` 转为中性文本或 `[x]` + “历史”标注。  
**优点**：降低误读概率；**缺点**：会改变清单视觉语义。

推荐采用 **方案 B**，但仅针对明确已完成的历史计划文档，避免影响仍处于规划/审核阶段的文档。

## 影响范围与验证

仅修改 Markdown 文档，范围限定在 Phase 0/Phase 1 历史计划文档与旧 Session Summary。验证使用 `python3 scripts/check_docs_commands.py`，确保文档命令无漂移。
